RESEARCH PROJECT

Soil Organic Carbon Prediction

Remote Sensing · Google Earth Engine · Machine Learning · SOC Mapping

Overview

This project investigates soil organic carbon prediction by integrating field-based SOC observations with satellite remote-sensing data and environmental predictors.

Research Focus

The workflow involves geospatial data preparation, satellite feature extraction, feature selection and machine-learning model development. Candidate modelling approaches include Random Forest, Support Vector Regression, XGBoost, CatBoost, LightGBM and Gradient Boosting.

Project Materials

Validated model-performance tables, measured-versus-predicted plots and spatial SOC prediction maps can be added here.
